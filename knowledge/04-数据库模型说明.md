# 04 · 数据库模型说明

> 数据库：PostgreSQL（`synapse_sq01`）  
> 与 Synapse IM 服务器**共享同一数据库**，分两类表：
> - **Synapse 原生表**（`users`、`rooms`、`events` 等）：由 Synapse 管理，web-api 只读，修改须走 Admin API
> - **业务扩展表**（`ext_` 前缀）：web-api 新增，负责存储业务扩展数据

## 二、关键扩展表结构说明

### 2.1 `ext_users` — 用户扩展信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 主键（ext_user_id） |
| `user_id` | varchar | Matrix MXID（`@username:homeserver`） |
| `nickname` | varchar | 昵称 |
| `avatar_url` | varchar | 头像 URL |
| `gender` | varchar | 性别 |
| `sign` | varchar | 个性签名 |
| `member_level_id` | int | 会员等级 ID（关联 ext_user_levels） |
| `member_expired_at` | timestamp | 会员到期时间 |
| `chat_prohibited` | bool | 聊天禁用标志 |
| `note_creation_prohibited` | bool | 禁止创建笔记 |
| `phone` | varchar | 绑定手机号 |
| `email` | varchar | 绑定邮箱 |

### 2.2 `ext_user_accounts` — 账户积分/诚信保

| 字段 | 类型 | 说明 |
|------|------|------|
| `user_id` | int | 关联 ext_users.id |
| `points` | bigint | 积分余额 |
| `credit_amount` | bigint | 诚信保余额（同步到 ext_circle_users.user_score） |

### 2.3 `ext_user_levels` — 会员等级配置

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 等级 ID（10001=初级, 10002=高级, 10003=超级） |
| `level_name` | varchar | 等级名称 |
| `is_exchangeable` | bool | 是否可积分兑换 |
| `exchange_cost` | int | 兑换所需积分 |
| `max_notes_created` | int | 最大创建笔记数（-1=不限） |
| `max_notes_per_wall` | int | 每墙最大笔记数（-1=不限） |
| `max_super_note_wall` | int | 超级笔记墙数量上限（-1=不限） |
| `friend_limit` | int | 好友上限 |
| `status` | tinyint | 状态（1=启用） |

### 2.4 `ext_circles` — 圈子

| 字段 | 类型 | 说明 |
|------|------|------|
| `circle_id` | varchar | 圈子 ID |
| `circle_name` | varchar | 圈子名称 |
| `circle_avatar_url` | varchar | 头像 |
| `circle_description` | text | 描述 |
| `circle_type` | varchar | 类型（public/private） |
| `owner_id` | varchar | 圈主 Matrix user_id |
| `status` | tinyint | 状态（0=待审核 1=通过） |
| `ban_status` | tinyint | 禁止发帖 |
| `limit_level_status` | tinyint | 入圈等级限制开关 |
| `limit_level` | varchar | 允许入圈的等级列表 |
| `limit_views_level_status` | tinyint | 浏览等级限制 |
| `invitation_code_count` | int | 需要邀请人数才能申请 |
| `member_limit` | int | 成员上限 |

### 2.5 `ext_circle_users` — 圈子成员

| 字段 | 类型 | 说明 |
|------|------|------|
| `circle_id` | varchar | 圈子 ID |
| `user_id` | varchar | Matrix user_id |
| `role_type` | varchar | 角色（owner/admin/member） |
| `user_nickname` | varchar | 成员昵称（冗余字段，资料同步） |
| `user_avatar_url` | varchar | 成员头像（冗余字段，资料同步） |
| `user_score` | int | 诚信保分数（与 ext_user_accounts.credit_amount 同步） |
| `can_view_help` | bool | 是否可浏览帮办 |
| `can_post_help` | bool | 是否可发布帮办 |
| `status` | tinyint | 状态（1=正常） |

### 2.6 `ext_user_notes` — 笔记

| 字段 | 类型 | 说明 |
|------|------|------|
| `user_id` | varchar | 作者 Matrix user_id |
| `title` | varchar | 标题 |
| `content` | text | 内容 |
| `type` | tinyint | 0=普通笔记 1=超级笔记 |
| `status` | tinyint | 0=草稿 1=正常 2=下架 |
| `pin` | tinyint | 是否置顶 |
| `pin_time` | int | 置顶时间戳 |
| `groups` | varchar | 所属分组 |
| `city` | varchar | 所在城市 |
| `images` | text | 图片 URL（逗号分隔） |
| `verify_video` | varchar | 视频 |
| `remark` | text | 备注（仅作者可见） |
| `remark_friends` | text | 好友备注 |

### 2.7 `ext_verify_codes` — 验证码记录

| 字段 | 类型 | 说明 |
|------|------|------|
| `contact_type` | varchar | `phone` 或 `mail` |
| `contact_value` | varchar | 手机号或邮箱 |
| `verify_type` | varchar | 用途（register/bind_account/rebind_verify_old 等） |
| `code` | varchar | 验证码 |
| `status` | tinyint | 1=已发送 2=已使用 3=已过期 |
| `created_at` | timestamp | 发送时间（用于限流统计） |

### 2.8 聊天分组相关表

| 表名 | 说明 |
|------|------|
| `ext_chat_groups` | 用户自定义聊天分组（id, user_id, name, icon） |
| `ext_group_users` | 分组内聊天室列表（group_id, room_id） |

## 三、Synapse 原生表（只读参考）

| 表名 | 说明 |
|------|------|
| `users` | 用户主表（name=MXID, password_hash, admin） |
| `users_v` / `users_v` 视图 | 包含 nickname、avatar_url 等的视图 |
| `access_tokens` | 登录 Token（device_id, token, user_id） |
| `rooms` | 房间/聊天室 |
| `room_memberships` | 房间成员关系 |
| `events` | 所有消息事件 |
| `devices` | 用户设备 |

> ⚠️ **注意**：Synapse 原生表中的用户数据（密码、设备等）修改必须通过 **Synapse Admin API**，不可直接写库。

## 四、数据关系图（简化）

```
users (Synapse)
  └──(name → user_id)──► ext_users (业务扩展)
                              └──(id → user_id)──► ext_user_accounts (积分账户)
                              └──(user_id)──► ext_circle_users (圈子成员)
                              └──(user_id)──► ext_user_notes (笔记)
                              └──(user_id)──► ext_chat_groups (聊天分组)
                              └──(member_level_id)──► ext_user_levels (等级配置)

ext_circles
  └──(circle_id)──► ext_circle_users
  └──(circle_id)──► ext_circle_content (帮办内容)
  └──(circle_id)──► ext_circle_notice (公告)
  └──(circle_id)──► ext_circle_invite (邀请/申请记录)
```
