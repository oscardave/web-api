## 二、框架 — Hyperf 3

Hyperf 是基于 Swoole 的 PHP 协程框架，`web-api` 使用的核心组件：

### 2.1 HTTP 服务
| 组件 | 说明 |
|------|------|
| `hyperf/http-server` | HTTP 路由与控制器（注解路由 `#[Controller]`、`#[GetMapping]`、`#[PostMapping]` 等） |
| `hyperf/framework` | 框架核心（DI 容器、事件、生命周期回调） |
| `hyperf/session` | Session 中间件（`SessionMiddleware`） |
| `hyperf/validation` | 参数校验中间件（`ValidationMiddleware`） |

### 2.2 数据层
| 组件 | 说明 |
|------|------|
| `hyperf/database` | Eloquent ORM（`Model` 基类，`Db::table()` 查询构造器） |
| `hyperf/database-pgsql` | PostgreSQL 驱动 |
| `hyperf/db-connection` | 协程连接池（默认 1-64 连接，超时 5s） |
| `hyperf/model-cache` | 模型级 Redis 缓存，TTL 24h，key 格式 `mc:%s:m:%s:%s:%s` |
| `hyperf/redis` | Redis 协程客户端 |
| `hyperf/paginator` | 分页器 |

### 2.3 消息/任务/定时
| 组件 | 说明 |
|------|------|
| `hyperf/async-queue` | 异步队列（Redis 驱动） |
| `hyperf/crontab` | 定时任务（注解 `#[Crontab]`） |
| `hyperf/task` | Task 进程（阻塞任务卸载到 Task Worker） |
| `hyperf/process` | 常驻进程（如 WS Redis 订阅进程） |

### 2.4 工具
| 组件 | 说明 |
|------|------|
| `hyperf/cache` | 缓存抽象层 |
| `hyperf/logger` | Monolog 日志 |
| `hyperf/guzzle` | 协程化 Guzzle HTTP 客户端 |
| `hyperf/elasticsearch` | ES 客户端 |
| `hyperf/translation` | 国际化 i18n |
| `hyperf/view` + `duncan3dc/blade` | Blade 模板引擎（后台页面） |
| `hyperf/constants` | 常量枚举 |
| `hyperf/memory` | 内存表（Swoole Table） |

## 三、数据库 — PostgreSQL

- **默认连接**：`synapse_sq01` 数据库（与 Synapse 共库）
- **驱动**：`pgsql`（Hyperf database-pgsql 扩展）
- **连接池**：最小 1，最大 64，心跳检测关闭（`heartbeat: -1`）
- **模型缓存**：Redis 驱动，前缀 `default`，TTL 3600×24 秒（24h）
- **模型生成路径**：`app/Model/`，继承 `App\Model\Model`

---

## 四、缓存 — Redis

Redis 在项目中承担多个职责：

| 用途 | Key 模式 | 说明 |
|------|----------|------|
| 模型缓存 | `mc:default:m:*` | Hyperf ModelCache 自动管理 |
| 用户 Session/Token | `UsersCache` 中封装 | 基于 access_token 查找用户 |
| WS 握手临时存储 | `ws_handshake:{fd}` | TTL 30s，onHandshake → onOpen 传递 ext_user_id |
| WS 连接映射 | `user_ws:{ext_user_id}` | SET 类型，存 `worker_id:fd` |
| WS fd 反查 | `ws_fd_uid:{worker_id}:{fd}` | TTL 7天，onClose 时查找用户 |
| 账变推送频道 | `account_change`（可配置） | Redis Pub/Sub，WS 进程订阅后推送给客户端 |
| Session | `hyperf/session` | 用于 Backend 管理后台登录态 |

---

## 五、WebSocket — 账变推送

- **处理器**：`app/WebSocket/AccountPushHandler.php`
- **握手鉴权**：只接受 `Authorization: Bearer <token>` Header，拒绝 URL query string token
- **流程**：
  ```
  onHandshake → 校验 token → 写 Redis ws_handshake:{fd}
  onOpen      → 读 Redis → 注册 user_ws:{ext_user_id} SET
  账变触发    → AccountChangeNotifyService.notify() → Redis PUBLISH
  Process     → Redis SUBSCRIBE → 找到 fd → server.push()
  onClose     → 清理 Redis 映射
  ```

## 八、中间件链（HTTP）

```
RouteLogMiddleware   → 记录所有路由访问日志
AdminLogger          → 记录管理后台操作到 syn_admin_logs
SessionMiddleware     → 处理 Session
ValidationMiddleware  → 全局参数校验
```

> **Backend 额外中间件**：`CheckAdminLogin`（检查管理员登录状态）
> **Frontend 通过注解**：`CheckLogin` 中间件或在控制器内调用 `UsersCache::getUserByRequest()` 校验 token
