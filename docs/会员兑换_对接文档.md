# 会员等级兑换接口对接文档

## 接口概述

用户使用积分兑换会员等级。仅支持初级(10001)、高级(10002)、超级(10003)三个等级，且目标等级需在后台配置为可兑换(`is_exchangeable=true`)。与当前等级相同时直接返回成功不扣费。

---

## 接口信息

| 项目 | 说明 |
|------|------|
| **请求方式** | POST |
| **接口路径** | `/api/v1/vip/exchangeMemberLevel` |
| **Content-Type** | application/json |
| **鉴权方式** | Bearer Token（Header） |

---

## 请求说明

### 请求头

| 参数名 | 必填 | 说明 |
|--------|------|------|
| Authorization | 是 | `Bearer <access_token>`，登录后获取的 access_token |

### 请求体

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| level_id | int | 是 | 目标会员等级 ID，仅支持 10001 / 10002 / 10003 |

**示例：**

```json
{
  "level_id": 10001
}
```

---

## 响应说明

### 成功响应

**实际发生扣费、账变时：**
```json
{
  "code": 0,
  "message": "兑换成功"
}
```

**当前已是目标等级、未扣费无账变时：**
```json
{
  "code": 0,
  "message": "您当前已是该会员等级，无需兑换"
}
```
前端可根据 `message` 区分展示（例如同等级时提示“您已是该等级，无需重复兑换”）。

### 失败响应

```json
{
  "code": 500,
  "message": "错误信息"
}
```

### 常见错误信息

| message | 说明 |
|---------|------|
| Access token is required | 未携带 access_token 或 Authorization 头为空 |
| 请选择要兑换的会员等级 | level_id 未传或为 0 |
| 等级ID无效，仅支持初级(10001)、高级(10002)、超级(10003) | level_id 不在允许范围内 |
| 目标等级不存在 | 等级在 ext_user_levels 中不存在 |
| 该等级不可兑换 | 目标等级 is_exchangeable 为 false |
| 积分余额不足 | 用户积分不足以支付兑换价格 |
| 升级价格无效，无法兑换 | 价格计算异常（如降级等） |
| 用户不存在 / 用户账户不存在 | 用户或账户数据异常 |

---

## 业务逻辑说明

1. **等级限制**：仅支持 10001（初级）、10002（高级）、10003（超级），且目标等级需 `is_exchangeable=true`。
2. **同等级**：当前会员等级与目标等级相同时，直接返回成功且不扣积分、不写账变，`message` 为「您当前已是该会员等级，无需兑换」，便于与真实扣费成功区分。
3. **价格计算**：复用后台会员等级兑换的价格逻辑（`UserExchangeDao::calcLevelUpgradePrice`）。
4. **扣费与账变**：扣减积分、写入账变记录、更新 `ext_users` 的 `member_level_id` 与 `member_expiration_time`，并插入 `ext_user_exchanges` 兑换记录。

## 调用示例

### cURL

```bash
curl -X POST "https://your-domain.com/api/v1/vip/exchangeMemberLevel" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"level_id": 10001}'
```

### JavaScript (fetch)

```javascript
fetch('/api/v1/vip/exchangeMemberLevel', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer ' + accessToken,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ level_id: 10001 })
})
  .then(res => res.json())
  .then(data => {
    if (data.code === 0) {
      console.log('兑换成功');
    } else {
      console.error(data.message);
    }
  });
```
