# 全局配置接口对接文档

## 接口说明

管理后台前端可通过该接口获取后端下发的全局配置项（如静态资源域名、IM 域名等），用于拼接资源地址或跳转链接。

---

## 请求

| 项目 | 说明 |
|------|------|
| **方法** | `GET` |
| **路径** | `/ht/v1/index/config` |
| **完整 URL 示例** | `https://your-api-host/ht/v1/index/config` |
| **鉴权** | 依现有管理后台鉴权方式（如需登录态则携带 Token） |
| **请求体** | 无 |

---

## 响应

### 成功响应

**HTTP 状态码**：`200`

**响应体结构**（统一 Backend 格式）：

```json
{
  "success": true,
  "message": null,
  "data": {
    "static_domain": "https://cdn.example.com",
    "im_domain": "https://im.example.com"
  }
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `success` | boolean | 是否成功 |
| `message` | string \| null | 错误或提示信息，成功时为 null |
| `data` | object | 全局配置对象 |
| `data.static_domain` | string | 静态文件域名（来自服务端 .env 的 `STATIC_DOMAIN`），用于拼接图片、附件等静态资源 URL |
| `data.im_domain` | string | IM 域名（来自服务端 .env 的 `IM_DOMAIN`），用于 IM 相关跳转或链接 |

---

## 前端使用示例

### 请求示例（axios）

```typescript
import request from '@/utils/request'; // 按项目实际封装替换

export function getGlobalConfig() {
  return request.get<{
    success: boolean;
    message: string | null;
    data: {
      static_domain: string;
      im_domain: string;
    };
  }>('/api/index/config');
}
```

若管理后台请求通过 Nginx/Vite 代理到 Backend，则前端调用的 path 一般为 **`/api/index/config`**（代理到 `http://web-api:9508/ht/v1/index/config`）。

### 使用示例

```typescript
const res = await getGlobalConfig();
if (res.data?.success && res.data?.data) {
  const { static_domain, im_domain } = res.data.data;
  // 拼接静态资源 URL
  const avatarUrl = `${static_domain}/uploads/avatars/xxx.png`;
  // 跳转 IM
  window.open(`${im_domain}/room/123`);
}
```

---

## 服务端配置

后端从 **`.env`** 读取并注入到该接口：

```env
STATIC_DOMAIN=https://your-cdn.example.com
IM_DOMAIN=https://im.example.com
```

未配置时接口仍返回成功，对应字段为空字符串 `""`。前端应对空字符串做兼容（如不拼接、使用默认域名等）。
