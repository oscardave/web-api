# 徽章配置接口对接文档

## 接口概述

提供**身份徽章**与**诚信徽章**的配置列表，供前端展示、下拉选择等使用。数据来源于表 `ext_user_badges`，直接返回表内字段。

| 类型     | type | 说明         |
|----------|------|--------------|
| 身份徽章 | 1    | 用户身份类徽章（如纯发用户、圈中长老、官方客服） |
| 诚信徽章 | 2    | 诚信保相关徽章（如银盾/金盾/黑奢担保）         |

---

## 一、身份徽章列表

### 接口信息

| 项目 | 说明 |
|------|------|
| **请求方式** | GET |
| **接口路径** | `/api/v1/configs/identityBadges` |
| **鉴权方式** | Bearer Token（Header） |

### 请求头

| 参数名 | 必填 | 说明 |
|--------|------|------|
| Authorization | 是 | `Bearer <access_token>`，登录后获取的 access_token |

### 成功响应

```json
{
  "code": 0,
  "message": "",
  "data": {
    "badges": [
      {
        "id": 10000,
        "name": "纯发用户",
        "type": 1,
        "icon_url": "/static/badges/identity/pure_user.png",
        "points_exchange_cost": 0,
        "membership_level_required": 0,
        "integrity_score_required": 0,
        "invited_users_required": 0,
        "monthly_help_posts_required": 0,
        "is_exchangeable": false,
        "description": "纯发用户身份徽章，用于标识基础用户身份",
        "sort_order": 1,
        "status": 1,
        "created_at": "2025-01-01 00:00:00+00",
        "updated_at": "2025-01-01 00:00:00+00"
      }
    ]
  }
}
```

### data.badges[] 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 徽章 ID，主键 |
| name | string | 徽章名称 |
| type | int | 徽章类型，本接口固定为 1（身份徽章） |
| icon_url | string | 徽章图标 URL |
| points_exchange_cost | int | 积分兑换所需积分 |
| membership_level_required | int | 会员等级要求 |
| integrity_score_required | int | 诚信保分值要求（身份徽章多为 0） |
| invited_users_required | int | 累计邀请入圈人数要求 |
| monthly_help_posts_required | int | 月发布帮办数量要求 |
| is_exchangeable | bool | 是否可被兑换 |
| description | string | 徽章描述 |
| sort_order | int | 排序权重，升序 |
| status | int | 状态：1-正常，2-禁用 |
| created_at | string | 创建时间 |
| updated_at | string | 更新时间 |

### 失败响应

```json
{
  "code": 500,
  "message": "错误信息"
}
```

### 常见错误

| message | 说明 |
|---------|------|
| Access token is required / 未登录或 token 无效 | 未携带或无效的 Authorization |

## 二、诚信徽章列表

### 接口信息

| 项目 | 说明 |
|------|------|
| **请求方式** | GET |
| **接口路径** | `/api/v1/configs/creditBadges` |
| **鉴权方式** | Bearer Token（Header） |

### 请求头

| 参数名 | 必填 | 说明 |
|--------|------|------|
| Authorization | 是 | `Bearer <access_token>`，登录后获取的 access_token |

### 成功响应

```json
{
  "code": 0,
  "message": "",
  "data": {
    "badges": [
      {
        "id": 10003,
        "name": "银盾担保",
        "type": 2,
        "icon_url": "/static/badges/integrity/silver_shield.png",
        "points_exchange_cost": 0,
        "membership_level_required": 0,
        "integrity_score_required": 500,
        "invited_users_required": 0,
        "monthly_help_posts_required": 0,
        "is_exchangeable": false,
        "description": "银盾担保徽章，需要500诚信保分值",
        "sort_order": 1,
        "status": 1,
        "created_at": "2025-01-01 00:00:00+00",
        "updated_at": "2025-01-01 00:00:00+00"
      }
    ]
  }
}
```

### data.badges[] 字段说明

与「身份徽章」相同，仅 **type 固定为 2**（诚信徽章），**integrity_score_required** 表示达到该诚信保分值即可获得该徽章。

### 失败响应

同身份徽章接口。

## 调用示例

### 身份徽章（cURL）

```bash
curl -X GET "https://your-domain.com/api/v1/configs/identityBadges" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### 诚信徽章（cURL）

```bash
curl -X GET "https://your-domain.com/api/v1/configs/creditBadges" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### JavaScript (fetch)

```javascript
// 身份徽章
const res = await fetch('/api/v1/configs/identityBadges', {
  headers: { 'Authorization': 'Bearer ' + accessToken }
});
const { code, data } = await res.json();
if (code === 0) {
  const identityBadges = data.badges; // 身份徽章列表
}

// 诚信徽章
const res2 = await fetch('/api/v1/configs/creditBadges', {
  headers: { 'Authorization': 'Bearer ' + accessToken }
});
const { code: code2, data: data2 } = await res2.json();
if (code2 === 0) {
  const creditBadges = data2.badges; // 诚信徽章列表
}
```

## 三、圈子徽章列表

### 接口信息

| 项目 | 说明 |
|------|------|
| **请求方式** | GET |
| **接口路径** | `/api/v1/configs/circleBadges` |
| **鉴权方式** | Bearer Token（Header） |

### 说明

返回启用的圈子徽章列表（ext_circle_badges 表 status=1）。C 端可根据 profile 接口返回的 `circle_badge_id` 在此列表中查找对应徽章的 `icon_url` 用于展示。

### 成功响应

```json
{
  "code": 0,
  "message": "",
  "data": {
    "badges": [
      {
        "id": 10000,
        "name": "示例圈子徽章",
        "icon_url": "/static/badges/circle/example.png",
        "remark": "备注",
        "sort_order": 1
      }
    ]
  }
}
```

### data.badges[] 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 徽章 ID，与 profile 的 circle_badge_id 对应 |
| name | string | 徽章名称 |
| icon_url | string | 徽章图标 URL |
| remark | string | 备注 |
| sort_order | int | 排序权重 |
