# 前台上传接口 - 前端对接文档

## 概述

C 端（前台）图片上传接口，与后台上传逻辑一致：仅允许图片、按文件内容检测 MIME、约 5MB 限制，需**登录态**（Bearer Token）。

**基础路径**: `/api/v1/upload`  
**认证**: 请求头 `Authorization: Bearer <access_token>`

### 与后台上传、多表及 Synapse 的关系

- **上传图片**（`POST /api/v1/upload/image`）：仅落盘并返回 url，**不**更新业务表、**不**请求 Synapse；适合通用图片（如笔记配图）。
- **上传头像**（`POST /api/v1/upload/avatar`）：上传后**直接设为当前用户头像并生效**，与后台「上传后点击保存」效果一致，内部走 `UserExtDao::updateProfile`，会更新 ext_users、profiles、圈子/群组等业务表并请求 Synapse（1v1 聊天、群聊、通讯录即时更新）。前台无需再调 `PUT profile/avatar_url`。
- 后台：先调后台上传拿到 url，再在管理后台点击「保存」提交更新用户头像，后端同样走 `UserExtDao::updateProfile`。

## 上传头像（直接生效）

用于 C 端用户更换头像：上传成功后即写入各业务表并同步 Synapse，**无需再调保存接口**。

### 接口信息

| 项目 | 说明 |
|------|------|
| 请求方式 | `POST` |
| 请求路径 | `/api/v1/upload/avatar` |
| Content-Type | `multipart/form-data` |
| 鉴权 | 必填，Header 中携带 `Authorization: Bearer <token>` |

### 请求参数

与「上传图片」相同：`file`（必填）、`field`（可选，默认 `file`）。约束同：仅图片、≤5MB。

### 响应格式

与「上传图片」相同。成功时 `data` 含 `url`、`fileName`、`fileSize`；此时头像已更新并同步，前端可直接用 `data.url` 展示或拼接完整 URL。

### 请求示例

```javascript
const formData = new FormData();
formData.append('file', file);

const res = await fetch('/api/v1/upload/avatar', {
  method: 'POST',
  headers: { 'Authorization': `Bearer ${accessToken}` },
  body: formData,
});
const data = await res.json();
// data.code === 0 时头像已生效，可直接用 data.data.url 更新 UI
```

## 上传图片（通用）

### 接口信息

| 项目 | 说明 |
|------|------|
| 请求方式 | `POST` |
| 请求路径 | `/api/v1/upload/image` |
| Content-Type | `multipart/form-data` |
| 鉴权 | 必填，Header 中携带 `Authorization: Bearer <token>` |

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | File | 是 | 图片文件，表单字段名默认为 `file` |
| field | string | 否 | 表单中文件字段名，不传则使用 `file` |

### 约束说明

- **类型**：仅图片，服务端按**文件内容**检测 MIME，允许：
  - PNG、JPEG/JPG、GIF、BMP、WebP
- **大小**：单文件 ≤ **5MB**（5,242,880 字节）
- **存储**：保存到服务器按月的目录，返回**相对路径**，如 `/uploads/202503/20250310120000Tabcd.jpg`。前端展示时需自行拼接站点域名（或配置的静态资源域名）。

### 请求示例

**cURL**

```bash
curl -X POST "https://your-domain/api/v1/upload/image" \
  -H "Authorization: Bearer <access_token>" \
  -F "file=@/path/to/photo.jpg"
```

**JavaScript (FormData)**

```javascript
const formData = new FormData();
formData.append('file', file); // file 为 File 对象

const res = await fetch('/api/v1/upload/image', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${accessToken}`,
  },
  body: formData,
});
const data = await res.json();
```

**JavaScript (axios)**

```javascript
const formData = new FormData();
formData.append('file', file);

const { data } = await axios.post('/api/v1/upload/image', formData, {
  headers: {
    'Authorization': `Bearer ${accessToken}`,
    'Content-Type': 'multipart/form-data',
  },
});
```

### 响应格式

与现有前台接口一致：`code`、`message`、`data`。

**成功（HTTP 200）**

```json
{
  "code": 0,
  "message": "",
  "data": {
    "url": "/uploads/202503/20250310120000Tabcd.jpg",
    "fileName": "/uploads/202503/20250310120000Tabcd.jpg",
    "fileSize": 123456
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| data.url | string | 相对路径，用于展示或提交给业务接口时拼接域名 |
| data.fileName | string | 同 url |
| data.fileSize | number | 文件大小（字节） |

**失败（HTTP 200，code ≠ 0）**

```json
{
  "code": 500,
  "message": "错误描述"
}
```

常见 `message` 示例：

- `Access token is required`：未传或未带 Token
- `无法获取上传文件信息`：未收到有效文件或字段名不是 `file`（且未传 `field`）
- `上传文件无效`：文件对象无效
- `上传文件大小超出限制`：超过约 5MB
- `无法识别文件类型` / `不允许的文件类型: xxx`：非允许的图片类型
- `上传失败`：服务端保存失败等

**Token 无效/过期（如 code 501）**

按现有前台约定处理（如跳转登录）。

### 前端使用建议

1. **展示图片**：使用 `data.url` 与静态资源域名拼接，例如：`const fullUrl = `${staticBaseUrl}${data.url}`;`
2. **提交业务接口**：若业务接口要求“图片路径”，一般直接传 `data.url` 或 `data.fileName` 即可（相对路径）。
3. **用作头像时**：请直接调 **`POST /api/v1/upload/avatar`**，上传成功后头像即生效（多表 + Synapse），无需再调 `PUT profile/avatar_url`。
4. **上传前校验**：可在前端先校验类型与大小，减少无效请求；最终以服务端校验为准。
5. **不要设置 Content-Type**：使用 FormData 时由浏览器自动带 `multipart/form-data` 和 boundary，不要手动写死 `Content-Type`，否则可能丢 boundary。

## 接口汇总

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 上传头像（直接生效） | POST | /api/v1/upload/avatar | 上传后即设为当前用户头像并同步多表与 Synapse，需登录 |
| 上传图片（通用） | POST | /api/v1/upload/image | 仅落盘返回 url，不更新头像，需登录 |
