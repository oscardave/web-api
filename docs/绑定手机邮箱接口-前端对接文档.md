# 绑定手机/邮箱接口 - 前端对接文档

本文档描述 web-api 提供的 C 端绑定手机号、绑定邮箱接口，供前端在「我的页面 - 隐私安全」等场景对接使用。

**基础路径**：`/api/v1`

**认证方式**：绑定接口需用户已登录，请求时携带 `Authorization: Bearer <access_token>` 或项目约定的 Token 方式。

---

## 一、绑定手机号

绑定流程分为两步：**① 发送验证码** → **② 提交绑定**。发送验证码复用现有接口，传入 `verify_type: "bind_account"`。

### 1.1 发送绑定手机验证码

**接口路径**：`POST /api/v1/index/phone-verify-code`

复用「发送手机验证码」接口，将 `verify_type` 设为 `bind_account`。

**请求示例**：
```json
{
  "phone": "13800138000",
  "verify_type": "bind_account"
}
```

**成功响应**：
```json
{
  "code": 0,
  "message": "验证码发送成功"
}
```

### 1.2 提交绑定手机号

**接口路径**：`POST /api/v1/users/bind-phone`

**用途**：校验验证码后，将当前用户的 `bound_phone` 更新为指定手机号。

**认证**：需登录，携带 Token。

**请求参数**

| 参数         | 类型   | 必填 | 说明           |
|--------------|--------|------|----------------|
| phone        | string | 是   | 手机号，11 位，1 开头 |
| verify_code  | string | 是   | 6 位数字验证码  |

**请求示例**：
```json
{
  "phone": "13800138000",
  "verify_code": "123456"
}
```

**成功响应**：
```json
{
  "code": 0,
  "message": "绑定成功"
}
```

**错误响应**：
```json
{
  "code": 非0,
  "message": "错误描述"
}
```

**常见错误**

| message                     | 说明                     |
|-----------------------------|--------------------------|
| 请先登录                    | 未携带或 Token 无效      |
| 手机号不能为空              | 未传 phone               |
| 手机号格式不正确            | 非 1 开头 11 位          |
| 验证码不能为空              | 未传 verify_code         |
| 验证码无效、已过期或已使用  | 验证码错误或过期         |
| 该手机号已被其他用户绑定    | 手机号已被占用           |

### 1.3 绑定手机号流程

```
1. 用户输入手机号
2. 调用 发送手机验证码（verify_type: "bind_account"）
3. 用户输入收到的验证码
4. 调用 提交绑定手机号（POST /api/v1/users/bind-phone）
5. 成功后可在用户资料中看到已绑定手机号
```

## 三、接口汇总

| 接口           | 路径                                   | 方法 | 认证 | 说明                     |
|----------------|----------------------------------------|------|------|--------------------------|
| 发送手机验证码 | /api/v1/index/phone-verify-code       | POST | 否   | verify_type=bind_account |
| 发送邮箱验证码 | /api/v1/index/email-verify-code       | POST | 否   | verify_type=bind_account |
| 绑定手机号     | /api/v1/users/bind-phone              | POST | 是   | phone + verify_code      |
| 绑定邮箱       | /api/v1/users/bind-email              | POST | 是   | email + verify_code      |

---

## 四、前端注意

- 验证码 5 分钟内有效，建议发送成功后启动 60 秒倒计时
- 绑定接口需在请求头携带登录 Token
- 绑定成功后，可通过 `GET /api/v1/users/profile` 获取最新 `bound_phone`、`bound_email` 展示
