# 登录注册接口 - 前端对接文档

本文档描述 web-api（PHP）提供的 C 端登录、注册及验证码相关接口，供前端对接使用。

**基础路径**：`/api/v1`

---

## 一、发送手机验证码

**接口路径**：`POST /api/v1/index/phone-verify-code`

**用途**：注册、登录、重置密码等场景下，向指定手机号发送 6 位数字验证码。

### 请求参数

| 参数         | 类型   | 必填 | 说明                                                         |
|--------------|--------|------|--------------------------------------------------------------|
| phone        | string | 是   | 手机号，11 位，1 开头（如 13800138000）                       |
| verify_type  | string | 否   | 验证类型，默认 `register`。可选：`register`、`login`、`reset_password` |

### 请求示例

```json
{
  "phone": "13800138000",
  "verify_type": "register"
}
```

### 成功响应

```json
{
  "code": 0,
  "message": "验证码发送成功"
}
```

### 错误响应

```json
{
  "code": 非0,
  "message": "错误描述"
}
```

### 常见错误

| message                     | 说明                     |
|-----------------------------|--------------------------|
| 手机号不能为空              | 未传 phone               |
| 手机号格式不正确            | 非 1 开头 11 位          |
| 验证码发送过于频繁，请5分钟后再试 | 60 秒内重复请求          |

### 前端注意

- 验证码 5 分钟内有效
- 建议发送成功后启动 60 秒倒计时，防止重复点击

| verify_type  | string | 否   | 验证类型，默认 `register`。可选：`register`、`login`、`reset_password` |

### 请求示例

```json
{
  "email": "user@example.com",
  "verify_type": "register"
}
```

### 成功响应

```json

  "message": "验证码发送成功"

```

### 错误响应

同「发送手机验证码」。

### 常见错误

| message                     | 说明                     |

| 验证码发送过于频繁，请5分钟后再试 | 60 秒内重复请求          |

## 三、检查用户名或手机号是否已注册

**接口路径**：`POST /api/v1/register/check-available`

**用途**：注册页输入框实时校验。前端传入用户名称或手机号，后端根据格式自动判断并按「用户名」或「手机号」查询是否已注册，便于在用户输入时提示「用户名已被使用」或「该手机号已注册」。

### 请求参数

| 参数         | 类型   | 必填 | 说明                                                                 |
|--------------|--------|------|----------------------------------------------------------------------|
| keyword      | string | 是   | 用户名称（用户名）或手机号；后端根据格式自动判断：符合 1 开头 11 位或 86+11 位则按手机号查，否则按用户名（localpart）查 |
| home_server  | string | 否   | homeserver 域名，默认 `im-sq01.bleiworc.xyz`（与注册接口一致）       |

### 判断规则

- **手机号**：`1[3-9]` 开头的 11 位数字，或 `86` + 11 位数字，则按手机号在 `ext_users.bound_phone` 中查询是否已注册。
- **用户名**：其余情况视为用户名（localpart），转为小写后按 2–100 字符、仅允许 `a-z0-9._-` 校验格式；再在 `users` 表中查 `@localpart:home_server` 是否已存在。

### 请求示例

```json
{
  "keyword": "alice"
}
```

```json
{
  "keyword": "13800138000"
}
```

### 成功响应

`code` 为 0 时，`data` 中：

| 字段   | 类型    | 说明                                                         |
|--------|---------|--------------------------------------------------------------|
| exists | boolean | 是否已注册：`true` 表示该用户名或手机号已被使用               |
| type   | string \| null | 仅当 `exists === true` 时有意义：`username` 表示用户名已被使用，`phone` 表示手机号已注册；未注册时为 `null` |

```json
{
  "code": 0,
  "message": "",
  "data": {
    "exists": false,
    "type": null
  }
}
```

已注册示例（用户名已被使用）：

```json
{
  "code": 0,
  "message": "",
  "data": {
    "exists": true,
    "type": "username"
  }
}
```

已注册示例（手机号已注册）：

```json
{
  "code": 0,
  "message": "",
  "data": {
    "exists": true,
    "type": "phone"
  }
}
```

### 错误响应

参数错误或格式错误时返回 `code` 非 0：

```json
{
  "code": 500,
  "message": "错误描述"
}
```

### 常见错误

| message                           | 说明                     |
|-----------------------------------|--------------------------|
| 请输入用户名称或手机号            | keyword 为空或仅空白     |
| 用户名长度为 2-100 个字符        | 按用户名校验时长度不符   |
| 用户名仅支持小写字母、数字、点、下划线、横线 | 按用户名校验时含非法字符 |
| 系统错误，请稍后重试              | 后端异常                 |

### 前端建议

- 在注册页「用户名称」或「手机号」输入框失焦（blur）时调用本接口；也可在点击「获取验证码」或「注册」前调用。
- 根据 `data.exists` 与 `data.type` 展示提示：`type === 'username'` 提示「用户名已被使用」，`type === 'phone'` 提示「该手机号已注册」。

## 四、用户注册

**接口路径**：`POST /api/v1/index/register`

**用途**：使用手机号或邮箱 + 验证码 + 密码 + **用户名**完成注册。**注册前必须先调用发送验证码接口**。注册成功后，**Matrix ID** 为 `@{username}:home_server`（用户名会转为小写存储），登录时可用该用户名或手机号/邮箱登录。

### 请求参数

| 参数        | 类型   | 必填 | 说明                                                                 |
|-------------|--------|------|----------------------------------------------------------------------|
| phone       | string | 二选一 | 手机号（与 email 二选一）                                             |
| email       | string | 二选一 | 邮箱（与 phone 二选一）                                              |
| username    | string | 是   | **用户名**，作为账号（Matrix ID 的 localpart）。2–100 字符，仅支持小写字母、数字、`.`、`_`、`-`；后端会转为小写存储，且全局唯一 |
| password    | string | 是   | 密码，6–32 位                                                         |
| verify_code | string | 是   | 6 位数字验证码                                                        |
| invite_code | string | 否   | **邀请码**，即邀请人的 `ext_users.id`（数字）。传则校验存在且有效，并写入邀请关系、邀请人下级邀请数 +1 |
| device_id   | string | 否   | 设备 ID，不传则自动生成                                               |
| device_name | string | 否   | 设备名称                                                              |

### 邀请码（invite_code）规则

- **可选**，不传则不影响注册。
- **含义**：邀请码 = 邀请人的 **ext_users.id**（数字，如 `10001`）。
- **校验**：若传了邀请码，后端会校验该 id 是否在 `ext_users` 中存在且有效（status=1）；不存在或无效则返回「邀请码无效」。
- **生效**：校验通过时，新用户的邀请人 ID、邀请人靓号等会写入，邀请人的「下级邀请人数」会 +1。

### 用户名（username）规则

- **必填**，不能为空。
- **长度**：2–100 个字符。
- **字符**：仅允许小写字母（a–z）、数字（0–9）、点（`.`）、下划线（`_`）、横线（`-`）。前端可先做校验或提示用户。
- **唯一性**：与已有用户不可重复，重复时返回「用户名已被使用」。
- **存储**：后端会统一转为**小写**后写入，展示名与 Matrix ID 的 localpart 均使用该小写用户名。

### 请求示例（手机号注册）

```json
{
  "phone": "13800138000",
  "username": "alice",
  "password": "MyPassword123",
  "verify_code": "123456",
  "device_name": "iPhone 15"
}
```

### 请求示例（邮箱注册）

```json
{
  "email": "user@example.com",
  "username": "bob",
  "password": "MyPassword123",
  "verify_code": "123456"
}
```

### 请求示例（带邀请码注册）

```json
{
  "phone": "13800138000",
  "username": "alice",
  "password": "MyPassword123",
  "verify_code": "123456",
  "invite_code": "10001",
  "device_name": "iPhone 15"
}
```

### 成功响应

返回 Synapse 格式的登录信息，可直接用于后续请求。`user_id` 即 Matrix ID，格式为 `@{用户名}:home_server`（用户名为小写）：

```json
{
  "user_id": "@alice:im-sq01.bleiworc.xyz",
  "access_token": "syt_xxxxxxxxxxxx",
  "home_server": "im-sq01.bleiworc.xyz",
  "device_id": "XXXXXXXX"
}
```

### 错误响应

```json
{
  "code": 非0,
  "message": "错误描述"
}
```

### 常见错误

| message                     | 说明                     |
|-----------------------------|--------------------------|
| 请提供手机号或邮箱          | 未传 phone 或 email      |
| 请提供用户名                | 未传 username（Controller 层） |
| 用户名不能为空              | username 为空或仅空白    |
| 用户名长度为 2-100 个字符   | 长度不符                 |
| 用户名仅支持小写字母、数字、点、下划线、横线 | 含非法字符       |
| 用户名已被使用              | 该用户名已被注册         |
| 密码不能为空                | 未传 password            |
| 验证码不能为空              | 未传 verify_code         |
| 密码长度必须在6-32位之间    | 密码长度不符             |
| 验证码无效、已过期或已使用  | 验证码错误或过期         |
| 该手机号已注册              | 手机号已被注册           |
| 该邮箱已注册                | 邮箱已被注册             |
| 邀请码无效                  | 传了 invite_code 但对应 ext_users.id 不存在或无效 |

## 五、用户登录

**接口路径**：`POST /api/v1/login/login`

**用途**：使用账号 / 靓号 / 手机号 / 邮箱 + 密码登录。

### 请求参数

| 参数        | 类型   | 必填 | 说明                                      |
|-------------|--------|------|-------------------------------------------|
| identifier  | string | 是   | 账号、靓号、手机号或邮箱（任选其一）      |
| password    | string | 是   | 密码                                      |
| device_id   | string | 否   | 设备 ID，不传则自动生成                   |
| device_name | string | 否   | 设备名称                                  |

**identifier 支持格式**：

| 类型   | 示例                    | 说明                                                     |
|--------|-------------------------|----------------------------------------------------------|
| 账号   | `alice`、`@alice:im-sq01.bleiworc.xyz` | **用户名**（注册时填的 username，即 Matrix localpart）或完整 Matrix ID；历史账号也可能是 `u10001` 等形式 |
| 靓号   | `88888`、`6655665`      | 纯数字                                                   |
| 手机号 | `13800138000`           | 11 位手机号                                              |
| 邮箱   | `user@example.com`      | 邮箱地址                                                 |

### 兼容旧版参数

支持 `phone` 或 `email` 作为 `identifier` 的替代：

```json
{"phone": "13800138000", "password": "xxx"}
{"email": "user@example.com", "password": "xxx"}
```

### 请求示例

```json
{
  "identifier": "13800138000",
  "password": "MyPassword123",
  "device_name": "iPhone 15"
}
```

### 成功响应

返回 Synapse 格式的登录信息。新注册用户的 `user_id` 为 `@{username}:home_server`：

```json
{
  "user_id": "@alice:im-sq01.bleiworc.xyz",
  "access_token": "syt_xxxxxxxxxxxx",
  "home_server": "im-sq01.bleiworc.xyz",
  "device_id": "XXXXXXXX"
}
```

### 错误响应

```json
{
  "code": 非0,
  "message": "错误描述"
}
```

### 常见错误

| message                     | 说明                     |
|-----------------------------|--------------------------|
| 密码不能为空                | 未传 password            |
| 请输入账号、靓号、手机号或邮箱 | 未传 identifier          |
| 用户不存在                  | 未找到对应用户           |
| 密码错误                    | 密码不正确               |

### 前端注意

- 登录成功后，将 `access_token` 保存到本地（如 localStorage）
- 后续请求在 Header 中携带：`Authorization: Bearer {access_token}`

## 八、忘记密码 / 重置密码

忘记密码流程分为两步：**① 发送验证码** → **② 提交重置密码**。发送验证码复用「一、发送手机验证码」和「二、发送邮箱验证码」，仅需传入 `verify_type: "reset_password"`。

### 8.1 发送重置密码验证码

复用「发送手机验证码」或「发送邮箱验证码」接口，将 `verify_type` 设为 `reset_password`。

**手机号示例**：
```json
POST /api/v1/index/phone-verify-code
{"phone": "13800138000", "verify_type": "reset_password"}
```

**邮箱示例**：
```json
POST /api/v1/index/email-verify-code
{"email": "user@example.com", "verify_type": "reset_password"}
```

### 8.2 提交重置密码

**接口路径**：`POST /api/v1/index/reset-password`

**用途**：校验验证码后，将用户密码重置为新密码。

### 请求参数

| 参数         | 类型   | 必填 | 说明                                      |
|--------------|--------|------|-------------------------------------------|
| phone        | string | 二选一 | 手机号（与 email 二选一）                 |
| email        | string | 二选一 | 邮箱（与 phone 二选一）                   |
| verify_code  | string | 是   | 6 位数字验证码                            |
| new_password | string | 是   | 新密码，6–32 位                           |

### 请求示例（手机号）

```json
{
  "phone": "13800138000",
  "verify_code": "123456",
  "new_password": "NewPassword123"
}
```

### 请求示例（邮箱）

```json
{
  "email": "user@example.com",
  "verify_code": "123456",
  "new_password": "NewPassword123"
}
```

### 成功响应

```json
{
  "code": 0,
  "message": "密码重置成功"
}
```

### 错误响应

```json
{
  "code": 非0,
  "message": "错误描述"
}
```

### 常见错误

| message                     | 说明                     |
|-----------------------------|--------------------------|
| 联系方式类型不能为空        | 未传 phone 或 email      |
| 联系方式不能为空            | phone/email 为空         |
| 验证码不能为空              | 未传 verify_code         |
| 新密码不能为空              | 未传 new_password        |
| 密码长度必须在6-32位之间    | 新密码长度不符           |
| 验证码无效、已过期或已使用  | 验证码错误或过期         |
| 用户不存在                  | 手机号/邮箱未注册        |
| 更新密码失败                | 系统异常                 |

### 忘记密码流程

```
1. 用户输入手机号或邮箱
2. 调用 发送手机验证码 或 发送邮箱验证码（verify_type: "reset_password"）
3. 用户输入验证码和新密码
4. 调用 提交重置密码
5. 成功后可使用新密码登录
```

## 九、典型流程

### 注册流程

```
1. 用户输入手机号/邮箱、用户名（可选先调用「检查用户名或手机号是否已注册」做实时校验）
2. 调用 发送手机验证码 或 发送邮箱验证码
3. 用户输入验证码、密码、用户名（username，必填，符合字符与长度规则）；可选填写邀请码（invite_code = 邀请人 ext_users.id）
4. 调用 用户注册
5. 成功返回 access_token、user_id（Matrix ID = @用户名:home_server），可直接视为已登录
```

### 登录流程

```
1. 用户输入 identifier（账号/靓号/手机号/邮箱）和密码
2. 调用 用户登录
3. 成功返回 access_token，保存并跳转首页
```

### 忘记密码流程

```
1. 用户输入手机号或邮箱
2. 调用 发送手机验证码 或 发送邮箱验证码（verify_type: "reset_password"）
3. 用户输入验证码和新密码
4. 调用 提交重置密码（POST /api/v1/index/reset-password）
5. 成功后可使用新密码登录
```
