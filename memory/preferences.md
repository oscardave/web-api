# Memory: Preferences

> 编码风格和工作流程偏好。影响 AI 生成代码的风格选择。
> 与 `docs/engineering-rules.md` 不冲突时生效；冲突时 `docs/` 优先。

---

## 编码偏好

### pref-001: 中文注释
- **内容**: 代码注释和文档优先使用中文
- **日期**: 2026-03-26

### pref-002: 错误处理风格
- **内容**: 优先使用 try-catch 包裹 Controller action，Dao 返回 error 字符串而非抛异常
- **日期**: 2026-03-26

### pref-003: 查询构建风格
- **内容**: 优先使用 Query Builder（`Db::table()->...`），复杂查询可用 raw SQL 并添加 PHPDoc
- **日期**: 2026-03-26

### pref-004: 分页参数
- **内容**: 分页使用 `page` + `pageSize`（而非 offset/limit），默认 page=1, pageSize=10
- **日期**: 2026-03-26

### pref-005: 命名语言
- **内容**: 变量名/方法名使用英文，数据库字段使用英文下划线命名
- **日期**: 2026-03-26

## 工作流偏好

### pref-006: 变更粒度
- **内容**: 优先小步变更（S 级），复杂任务拆分为多个 S 级
- **日期**: 2026-03-26

### pref-007: 文档同步
- **内容**: 核心代码变更后同步更新 knowledge/，保持文档新鲜度
- **日期**: 2026-03-26

### pref-008: commit 风格
- **内容**: 中文 commit message，简洁描述变更意图
- **日期**: 2026-03-26
